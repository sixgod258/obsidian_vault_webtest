# 🎯 测试靶标搭建（本地靶场）

> 安全类工具（ZAP、Nikto）需要一个**你完全有权扫描**的目标。推荐用 Docker 在本地启动一个故意含漏洞的靶场，测试结果稳定、可复现、无法律风险。

## 方案对比

| 靶场                                         | 特点                                 | 推荐场景                                                       |
| ------------------------------------------ | ---------------------------------- | ---------------------------------------------------------- |
| **OWASP Juice Shop**                       | 现代 Web 应用，含 OWASP Top 10 全部漏洞，前端复杂 | 首选，模拟真实业务系统                                                |
| **DVWA** (Damn Vulnerable Web Application) | 经典 PHP 靶场，按漏洞分类（SQLi、XSS、CSRF…）    | 专注单个漏洞类型的教学/验证                                             |
| **本地静态站点**（`python -m http.server`）        | 无漏洞，仅用于链接类/性能类工具演示                 | 测试 [[03-LinkChecker]]、[[04-Wget-Spider]]、[[01-Lighthouse]] |

> 前置条件：Docker Desktop（`docker --version` 验证）。

---

## 方案 A：OWASP Juice Shop（推荐）

### A1. 启动容器

```bash
docker pull bkimminich/juice-shop
docker run --rm -d -p 3000:3000 --name juice-shop bkimminich/juice-shop
```

### A2. 验证

浏览器打开 <http://localhost:3000>，看到 Juice Shop 商店页面即成功。

### A3. 常用信息

| 项目 | 值 |
|---|---|
| 首页地址 | `http://localhost:3000` |
| 管理员账号（供测试） | `admin@juice-sh.op`（密码可在游戏内获取/重置） |
| 文档 | <https://pwning.owasp-juice.shop/> |
| 停止容器 | `docker stop juice-shop` |

> Juice Shop 本身集成了计分板（Score Board），很适合顺带了解安全测试。

---

## 方案 B：DVWA

### B1. 启动容器

```bash
docker pull vulnerables/web-dvwa
docker run --rm -d -p 8080:80 --name dvwa vulnerables/web-dvwa
```

### B2. 验证与初始化

1. 浏览器打开 <http://localhost:8080>。
2. 默认账号 `admin` / `password`。
3. 进入后点击底部 **Create/Reset Database** 初始化数据库。
4. 在 **DVWA Security** 页把难度调到 `medium`（过低难度的 SQLi 已基本被浏览器/框架拦掉）。

---

## 方案 C：本地静态站点（无漏洞，性能/链接测试用）

用于跑 Lighthouse、LinkChecker、Wget --spider 这类**非攻击性**工具，也可以当作 ZAP 的被动扫描目标。

```bash
# 在任意含 index.html 的目录下启动
cd D:/your-site
python -m http.server 8888
```

访问 <http://localhost:8888> 验证。

> 如需生成一个"含各种链接"的测试页，可先用随机文章网站，或手动写几个互相链接的 HTML 文件。

## 靶场 ↔ 工具对应表

| 靶场 | 可测工具 | 说明 |
|---|---|---|
| Juice Shop (3000) | ZAP、Nikto、Lighthouse、WebPageTest | 安全工具主靶场 |
| DVWA (8080) | ZAP、Nikto | 安全教学专用 |
| 本地静态站 (8888) | LinkChecker、Wget --spider、Lighthouse | 链接与性能演示 |

> 扫描本地 Docker 容器时注意：容器网络里 Juice Shop 的地址就是宿主机 `localhost:3000`，各工具直接用该地址即可。
