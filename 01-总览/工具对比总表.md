## 按用途选工具

| 你的需求 | 推荐工具 |
|---|---|
| 一键拿到页面性能/SEO/可访问性评分 | [[01-Lighthouse]] |
| 想看到资源加载瀑布图、模拟不同网速/地域 | [[02-WebPageTest]] |
| 全站扫描 404/死链，出报告给运维 | [[03-LinkChecker]] |
| 快速确认一批 URL 是否有效（不装工具） | [[04-Wget-Spider]]（或 curl） |
| 上线前安全扫描、找漏洞 | [[05-OWASP-ZAP]] |
| 检查服务器版本、危险文件、已知漏洞 | [[06-Nikto]] |
| 全站 SEO 技术审核、重定向/Canonical 检查 | [[07-Screaming-Frog]] |

## 组合建议（分层防御）

```
日常巡检     → Wget --spider / LinkChecker（链接健康）
性能监控     → Lighthouse（CI 集成）+ WebPageTest（深度诊断）
上线前安全   → ZAP 被动扫描 + Nikto 服务器基线
SEO 审核     → Screaming Frog（低频、全站）
```

> 详细的分场景推荐见 [[选型建议]]。

## 进阶：用 Claude Code + Playwright 实现

> 7 款工具的核心功能都能用 **Claude Code 驱动 Playwright** 脚本化实现，靶标为本地 Juice Shop，7 款已全部实测完成（2026-08-06）。详见 `05-ClaudeCode-Playwright实现/`。

| 类别 | 可实现度 | 亮点 / 缺口 |
|---|---|---|
| 链接/SEO（Wget-Spider、LinkChecker、Screaming-Frog） | ✅ 完全 | SPA 检测比原工具更准 |
| 性能（Lighthouse、WebPageTest） | 🟡 核心 | Web Vitals 实测等价；缺专有评分/云端节点 |
| 安全（ZAP、Nikto） | 🟠 被动层 | 主动扫描深度与 CVE 库不可替代 |
