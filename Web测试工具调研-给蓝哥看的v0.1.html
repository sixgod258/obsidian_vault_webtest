二、工具总览（7 款）

Lighthouse

性能 · 体验

Google 官方工具，一键为页面打出性能、可访问性、SEO、最佳实践综合评分，并给出可执行的优化建议。性能评分的事实标准。

成本：免费开源　上手：★☆☆
本机直接运行报告：HTML/JSON

WebPageTest

性能 · 深度

深度性能诊断：资源加载瀑布图、多地域多网速模拟、首屏渲染过程回放。性能问题定位到具体资源的利器。

成本：免费（限量）　上手：★★☆
云端服务 · 免安装报告：在线 + JSON

LinkChecker

链接质量

全站递归死链检测，自动找出 404、超时、异常重定向等问题，输出 CSV / HTML / XML 报告，可直接交给运维处理。

成本：免费开源　上手：★★☆
Docker 一条命令报告：多格式

Wget --spider

链接 · 轻量

系统自带的链接有效性检查方式（Windows 可用 curl 等价实现）。极轻量，适合脚本化批量检查一批 URL 是否可用。

成本：免费　上手：★☆☆
零安装（curl）命令行输出

OWASP ZAP

安全 · 应用层

国际权威的开源 Web 应用安全扫描器（OWASP 官方）。自动发现 SQL 注入、XSS 等漏洞并按严重级别告警，支持 CI 自动化。业界标准。

成本：免费开源　上手：★★★★
Docker 自动化扫描报告：HTML/JSON

Nikto

安全 · 服务器层

Web 服务器配置与已知漏洞扫描（8000+ 检查项）：危险文件、过期组件、配置错误、信息泄露。快速摸清服务器底细。

成本：免费开源　上手：★★★
Docker 快速扫描报告：多格式

Screaming Frog

SEO · 全站

商业级全站 SEO 技术审核：标题、Meta、H1、重定向、Canonical 等数十项指标，可视化图表，适合定期的站点 SEO 体检。

成本：免费 ≤500 URL；付费约 £199/年
桌面软件导出：CSV/XLSX

四、安装与部署方式（每工具具体操作）

以下为各工具在 Windows 本机上的推荐安装方式。复杂度分 低中高 三档，均给出可直接使用的命令或下载入口。

JS

Lighthouse  低

npm install -g lighthouse
依赖 Node.js + Chrome（本机已装），一条命令全局安装。也可不装，直接用 npx 临时调用。
云

WebPageTest  低

① 网页直接使用  ② npm install -g webpagetest
① 浏览器打开 webpagetest.org 零安装；② CLI 方式需到官网免费申请 API key。
🐳

LinkChecker  低

docker pull ghcr.io/linkchecker/linkchecker:latest
Docker 方案最稳；备选：WSL 内 pip install linkchecker。Windows 原生 pip 可能遇编码兼容问题。
▼

Wget --spider  低

winget install GnuWin32.Wget
Windows 无原生 wget。更简单：本机已装 curl 自带 --head / -o 等等价功能，零安装直接用。
🐳

OWASP ZAP  中

docker pull ghcr.io/zaproxy/zaproxy:stable
Docker 镜像即用，免装 Java。扫描命令内置（zap-baseline.py），挂载目录即可输出报告。桌面版需额外装 JDK 17+。
🐳

Nikto  低

docker pull ghcr.io/sullo/nikto:latest
Docker 一条命令完成扫描，挂载目录输出 JSON/HTML 报告。原生方式需 Perl 环境（不推荐 Windows 裸装）。
🖥

Screaming Frog  低

官网下载：screamingfrog.co.uk/seo-spider → Download
Windows/Mac 桌面安装包，GUI 操作直观。免费版限 500 URL 且不可导出。CLI 自动化需付费授权。

五、可行性分析

关键结论：7 款工具全部可以免费或低门槛起步；其中 4 款（Lighthouse / ZAP / Nikto / LinkChecker）可通过 Docker 或 npm 在本机一键部署，与现有环境无缝兼容。

WebPageTest云端免费（限量）无（免安装）✅ npm CLI公共实例有限额；测内网需穿透
